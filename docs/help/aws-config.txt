AWS config page

This page stores the bootstrap shell commands that initialize your AWS credentials and default profile details for tunnel creation.

How to use it:
- Paste the exact AWS login or credential bootstrap commands you want to run in this container.
- Use the top Paste and Save action if you want to load the current clipboard into the textarea and immediately persist it.
- Save the configuration once the command is correct.

Requirements:
- The AWS profile, region, and any SSO or credential helpers must be valid for the environment where the tunnel is created.

If the command fails, the Output area and Exit code below the form show the exact failure details.

After this is configured, the Tunnels page can create outbound SSM or host-tunnel sessions without re-entering AWS credentials each time.
